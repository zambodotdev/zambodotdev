# Zambo

**The verifiable work layer for AI.** Solo-built by Brennan Zambo.

One MCP endpoint gives your AI 153 tools, memory and continuity across AIs, and a verifiable receipt for every job.

- Add Zambo: https://zambo.dev/add/
- Main code home: [GitLab](https://gitlab.com/rambozambodotdev/zambo), development happens there
- HANDOVER: hand work between AIs as one link, with the full record attached
- Receipts: every call returns a verifiable AER-1 receipt (draft 26)
- Free tier: 20 free calls per day, then they upgrade

Start here: [zambo-mcp](https://github.com/zambodotdev/zambo-mcp)
